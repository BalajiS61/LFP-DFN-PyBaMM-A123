# LFP Cell Physical Modelling & Parametrization in PyBaMM

DFN model of the **A123 ANR26650M1B** (LiFePO4 / graphite, 2.5 Ah) in PyBaMM: baseline simulation,
residual analysis, OCV / capacity calibration, parameter optimization and validation.

Case study for MEAtec. The measurement data are confidential and **not included** in this repository.

## Results in brief
| Model | HPPC coverage | HPPC RMSE | Time-weighted RMSE | Held-out HPPC levels | OCV error (rest points) |
|---|---|---|---|---|---|
| Task 2 - Prada2013, un-tuned | 56.6 % (stops: graphite diffusion limit) | 37.3 mV (0-14.3 h only) | 30.1 mV | - | 229.6 mV |
| Task 3 - calibrated OCV / capacity + graphite diffusivity | 100 % | 43.1 mV | 22.5 mV | 46.1 mV | 7.0 mV |
| **Task 4 - optimized (final)** | **100 %** | **40.9 mV** | **21.6 mV** | **44.5 mV** | **7.0 mV** |

Final parameters (`results/step4_final_model/optimized_parameters.json`): negative exchange-current density
1.082 x Prada2013, positive 9.52 x, graphite diffusivity 3.5e-14 m2/s, LFP diffusivity 1.77 x, contact
resistance 2.09 mOhm. Anode potential vs Li/Li+ falls below 0 V during 4C charge (-94 mV for 791 s):
lithium-plating risk region (plating not modelled).

Full methodology, decisions and discussion: `docs/report` (and the working log `docs/report_notes.md`).

## Final parameters and key plots (included in the repository)
- `parameters/optimized_parameters.json` - final optimized parameter set (copy of
  `results/step4_final_model/optimized_parameters.json`: values, formal uncertainties, correlations,
  per-test errors, optimizer settings)
- `parameters/ocv_calibration.json` - calibrated stoichiometry window and electrode capacities (Step 3c),
  needed together with the optimized parameters to rebuild the model
- `plots/` - the required plots: Step 2 measured vs simulated and voltage error, Step 5 measured vs
  simulated and voltage error, physical variables (anode potential vs Li/Li+) for HPPC and 4C charge,
  and the Step 4 training fit

## Setup
Tested with Python 3.13 and PyBaMM 26.9 on Windows 10.
```
python -m venv .venv
.venv\Scripts\Activate.ps1          (Windows PowerShell; on Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
```
If PowerShell blocks the activation script: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.

## Data
Place the six files provided by MEAtec in `data/`:
```
data/Charge_1C.mat   data/Charge_2C.mat   data/Charge_3C.mat   data/Charge_4C.mat
data/Discharge_1C.mat
data/HPPC.mat
```
Formats: charge files contain top-level vectors `Time`, `Current`, `Voltage`; `Discharge_1C.mat` and
`HPPC.mat` contain a struct `meas` with fields `Time`, `Current`, `Voltage`, `Ah`, ...
Sign convention in the files: charge current positive (flipped once in `data_loader.py`, PyBaMM uses
discharge positive).

## How to run (in order)
All commands from the project root with the virtual environment active. Outputs go to `results/<step>/`.

| Step | Command | What it does | Runtime* |
|---|---|---|---|
| 1 | `python src\data_loader.py` | loads and checks all data, overview plot | s |
| 1 | `python src\check_hppc_current.py` | HPPC current integrity (interpolation choice) | s |
| 2 | `python src\step2_baseline_hppc.py` | **Task 1-2**: DFN (Prada2013) on HPPC, plots, metrics | ~1 min |
| 2b | `python src\step2b_diagnose_stop.py` | why the baseline stops early (`--model calibrated` for 3c) | ~1 min |
| 3a | `python src\step3a_residual_analysis.py` | **Task 3**: residuals by phase / SOC, pulse resistance | s |
| 3b | `python src\step3b_ocv_analysis.py` | measured OCV (relaxation-corrected) vs Prada2013 | ~20 s |
| 3c | `python src\step3c_ocv_calibration.py` | OCV / capacity calibration, Q_p identifiability scan | ~3 min |
| 3d | `python src\step3d_hppc_calibrated.py` | HPPC with calibrated thermodynamics | ~1 min |
| 3e | `python src\step3e_diffusivity_scan.py` | graphite diffusivity sensitivity on HPPC | ~6 min |
| 4a | `python src\step4a_training_check.py` | training data, initial states, mesh check | ~4 min |
| 4 | `python src\step4_optimize.py --diagnose` | where the training error is (by phase) | ~1 min |
| 4b | `python src\step4b_dp_shape_probe.py --workers 3` | state-dependent diffusivity feasibility | ~10 min |
| 4c | `python src\step4c_bbot_feasibility.py --workers 3` | graphite low-x diffusivity vs HPPC feasibility (default mesh) | ~10 min |
| 4 | see below | **Task 4**: optimization | ~1-1.5 h |
| 5 | see below | **Task 5**: validation, physical variables | ~5 min |

\*on a 4-core laptop; use `--workers 2` or `3` if memory is limited.

Residual analysis of any run: `python src\step3a_residual_analysis.py --input <csv> --out <folder> --label "<name>"`.

### Task 4 - optimization
Final model (k_n, k_p, D_n, D_p + contact resistance; training = Charge 1C-4C constant-current parts,
Discharge 1C, HPPC odd SOC levels; HPPC even levels held out; default mesh):
```
python src\step4_optimize.py --fit k_n,k_p,D_n,D_p --init k_n=1.16,k_p=10.5,D_n=3.6e-14,D_p=0.37 --bounds D_n=3.5e-14:3e-13 --hppc-split --cost-window cc --mesh default --tag final_model --max-nfev 25 --workers 3
```
Earlier runs documented in the report (sensitivity / rejected variants): four constant parameters on all
training data (`--max-nfev 40`), graphite low-x diffusivity (`--fit k_n,D_n,D_p,b_bot`), coarse-mesh split fit.
Interrupted runs continue with `--resume`. Progress is saved after every evaluation
(`results/step4_<tag>/history.jsonl`, `best_so_far.json`); each evaluation line reports any test that
stops early.

### Task 5 - validation
```
python src\step5_validate.py --params results\step4_final_model\optimized_parameters.json --tag final_model
```
HPPC validation (default mesh), comparison baseline / Task 3 / optimized, time-weighted and rest-vs-dynamic
errors, training fits, anode potential vs Li/Li+ and other physical variables (HPPC and 4C charge).

## Optimized parameters
Saved as JSON: `results/step4_final_model/optimized_parameters.json` (fitted values, uncertainties,
correlations, training errors, settings). Reuse the final model:
```python
from final_model import load_optimized, optimized_parameter_values, simulate_optimized
opt = load_optimized(path)                     # path to optimized_parameters.json
pv, calib = optimized_parameter_values(opt)    # pybamm.ParameterValues (Prada2013-based)
```
The OCV / capacity calibration it builds on is `results/step3c/ocv_calibration.json`.

## Main assumptions and limitations
- Isothermal (test temperature 22.8-24.6 degC).
- Graphite OCP from Ecker2015 (another commercial graphite) - small staging mismatch (about +/-11 mV).
- No LFP hysteresis branch data in the measurements; no lithium plating model.
- The CV phase of the charge tests (cell held at 3.6 V) is not reproduced by the DFN and is excluded
  from the fit; its error is reported separately.
- The sharp end-of-discharge plunge at 1C is not reproduced: the graphite-diffusivity term that captures it
  makes the 15C HPPC pulses fail at low SOC (single-particle-size DFN limit).
- Charge tests: the first 0.15 Ah (cell still relaxing from the preceding discharge) is excluded from the fit.
